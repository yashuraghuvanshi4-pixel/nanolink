# nanolink ⚡

> High-performance URL shortener & analytics engine featuring an interactive CLI, embedded microservice, and zero third-party dependencies.

Designed with fundamental system design principles:
- **Base62 ID Encoding & Collision Resolution**
- **HTTP 307 Temporary Redirection** (preventing cache skew)
- **Privacy-Preserving Click Analytics** (daily-salted IP hashing)
- **SQLite Persistence with WAL Mode**
- **Terminal ASCII QR Code Rendering**
- **Embedded Web Analytics Dashboard**
